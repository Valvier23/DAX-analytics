01 / How it works

From a spreadsheet
to a meaningful report.

The importer prepares your CSV files and creates a PBIP project with connected data sources, ready to open in Power BI Desktop.

01 — START WITH YOUR DATA

Start with what you have.

Select or drag an .xlsx or .xls file into the Windows importer. It detects worksheets and suggests an initial column mapping.

02 — MAKE IT CONSISTENT

Give every row context.

Confirm the mapping for employees and, optionally, medical leave. Save reusable profiles. Dates are standardised and invalid rows are excluded with a reason recorded for each one.

03 — SEE WHAT MATTERS

A report that makes sense.

Generate your CSV files and Power BI project. Check filas_rechazadas.csv for rejected rows, then open the report. Output is saved in the datos-procesados folder next to the importer.

04 / Before you start

Before you take
the next step.

Requirements, privacy and what the kit currently includes.

What do I need to use the kit?

The free kit includes a portable Windows x64 importer. You need Power BI Desktop installed. Download and extract the ZIP before opening the importer.

Who is it for?

HR professionals, People Analytics teams and business leaders who use Excel data to analyse headcount, workforce changes, turnover and absence.

Can I upload files to this website?

This website does not accept file uploads. The downloadable importer processes Excel locally and saves the CSV files and PBIP project on your computer. The web demo uses fictional data only.

Is the starter kit free?

The Free kit is free to download. The Plus template is available in the repository; paid plans and commercial support have not yet been set up.

What happens to invalid data?

Rows with missing required fields, duplicate IDs, inconsistent dates or leave episodes for unknown employees are excluded. The reason is recorded in filas_rechazadas.csv. Review this file before interpreting the report.

What validation is still pending?

The executable is not yet digitally signed, so Windows may show a SmartScreen warning. Final visual checks on Windows 10 and 11 and performance testing with Excel files over 100,000 rows are still pending.
