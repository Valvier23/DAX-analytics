¿Qué necesito para empezar?

Un equipo Windows x64, Power BI Desktop y tu Excel. Descarga el kit, extrae el ZIP y abre el importador.

¿Dónde se procesan mis datos?

En tu equipo. El importador trabaja localmente; esta web no recibe tus archivos.

¿Qué incluye la descarga?

El importador, las versiones Demo y Plus del informe y datos de ejemplo. Elige por separado el idioma de la app y del informe.
