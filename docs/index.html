01 — EL PUNTO DE PARTIDA

Empieza con lo que tienes.

Selecciona o arrastra un .xlsx o .xls al importador de Windows. Detecta hojas y propone un mapeo inicial de cabeceras.

02 — PONER ORDEN

04 / Antes de empezar

Antes de dar
el siguiente paso.

Requisitos, privacidad y alcance del kit actual.

¿Qué necesito para utilizar el kit?

El kit gratuito incluye un importador portable para Windows x64. Necesitas Power BI Desktop instalado. Descarga y extrae el ZIP antes de abrir el importador.

¿Para quién está pensado?

Para profesionales de RR. HH., People Analytics y responsables de negocio que analizan plantilla, movimientos, rotación y absentismo a partir de Excel.

¿Puedo subir mis archivos en esta web?

Esta web no admite archivos. El importador descargable procesa Excel localmente y guarda los CSV y el proyecto PBIP en tu equipo. La demo web solo usa datos ficticios.

¿El kit gratuito tiene coste?

El kit Free se descarga gratuitamente. La plantilla Plus está en el repositorio; pago y soporte comercial están pendientes de configurar.

¿Qué ocurre con los datos incorrectos?

Se excluyen filas con campos obligatorios ausentes, IDs duplicados, fechas incoherentes o episodios de personas inexistentes. El motivo queda en filas_rechazadas.csv. Revisa ese archivo antes de interpretar el informe.

¿Qué validaciones están pendientes?

El ejecutable todavía no tiene firma digital y Windows puede mostrar un aviso de SmartScreen. Están pendientes la prueba visual final en Windows 10 y 11 y el rendimiento con Excel de más de 100.000 filas.
